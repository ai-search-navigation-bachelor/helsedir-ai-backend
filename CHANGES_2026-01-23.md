## API Bruk

### Søk (eksisterende)
```
GET /helsedir/search?QueryText=adhd
```

### Hent infobit (kun hovedinfo)
```
GET /helsedir/infobit/0006-0007-4569133a-5426-4072-a96b-3a4dc43def2e
```

### Hent infobit med kapitler (nivå 1)
```
GET /helsedir/infobit/0006-0007-4569133a-5426-4072-a96b-3a4dc43def2e?include_children=true
```

### Hent full struktur (nivå 2+)
```
GET /helsedir/infobit/0006-0007-4569133a-5426-4072-a96b-3a4dc43def2e?include_children=true&depth=2
```

## Frontend Anbefaling (Progressive Disclosure)

1. **Søk:** `GET /helsedir/search?QueryText=...` → Bare liste
2. **Klikk resultat:** `GET /helsedir/infobit/{id}?include_children=true&depth=1` → Hovedinfo + kapittelliste
3. **Klikk kapittel:** `GET /helsedir/infobit/{id}?include_children=true&depth=2` → Full struktur

Dette gir optimal ytelse og brukeropplevelse! 🚀
